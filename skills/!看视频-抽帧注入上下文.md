# videowatch — 视频 → 有序时间戳帧 → 上下文

SCRIPT `~/.config/term_agent/skill/videowatch.py`（168 行）
SCOPE 视频 → 自适应抽帧 → 帧差选帧 → 经 ctxinject 注入。产物落 `~/.cache/videowatch/<sha1[:10]>/`。
REF `memory/视频抽帧-1fps变帧检测与注入实测.md`

## CMD
```bash
python3 ~/.config/term_agent/skill/videowatch.py "<URL 或本地路径>" --pid PID
python3 ~/.config/term_agent/skill/videowatch.py /abs/x.mp4 --no-inject
```

## ARG
| 参数 | 默认 | 约束 |
|---|---|---|
| `src` | — | 本地路径或 `http(s)://`；本地须存在 |
| `--pid` | 无 | **注入时必填**；缺 → `err:need_pid`，`exit 1`；`--no-inject` 时可省 |
| `--thr` | `6.0` | 灰度均差阈值 0–255；调大→只留大变化 |
| `--max-frames` | `16` | 硬上限；超限按分数 top-N 保序 |
| `--long` | `480` | 帧长边；>512 无收益（宿主再压） |
| `--max-sec` | `900` | 时长闸门；超 → `err:too_long`，需显式调大 |
| `--no-inject` | off | 只出图 |
| `--quiet` | off | 不唤醒宿主（排队注入） |

## EXIT
| 码 | 含义 | 动作 |
|---|---|---|
| `0` | 帧已落地 | 读 `ev:inject_ok` |
| `1` | 参数/环境/依赖错 | 读 stderr `ev:err` |
| `2` | argparse（缺 `src`） | 补参数 |
| `3` | 已排队 | 读 `ev:inject_defer.log`，勿重跑 |
| `4` | 落地图数 ≠ 应注入数 | 查 `got/want` |
| `5` | 关键帧全空场，未注入 | 调 `--thr`；或定点抽帧 |

## EV（stdout 单行 JSON）
| ev | 字段 | 含义 |
|---|---|---|
| `plan` | `src,size,dur,fps,all_frames,frame_px,keep,thr,cut,long,frames[{sec,p,mean}]` | 抽帧结果；后续分析直接读它或 `manifest.json` |
| `fetch_reuse` / `fetching` / `fetch_done` | `name,mb` / `url` | 下载态 |
| `inject_ok` | `got,want,hist_len` | 落地自检 |
| `inject_defer` | `log` | 看守日志路径 |
| `inject_err` | `rc,stderr` | ctxinject 调用失败 |
| `empty` | `maxmean` | 全空场（`<2`） |
| `err`(stderr) | `msg` | `need_pid` / `no_such_file` / `no_video_stream` / `too_long` / `missing_bin` / `cmd_fail` |

## ARTIFACT
```
~/.cache/videowatch/<sha1[:10]>/
  src.<ext> | f1/f%05d.jpg（全量） | out/t<毫秒>_i<序>.jpg（入选帧） | manifest.json
```
`manifest.json`：`frames[{t,sec,i,n,p}]`；报时间用 `sec`，勿解析文件名。

## FRAMING
基础帧率按时长自适应：`<30s→5fps`、`<120s→2fps`、`≥120s→1fps`。选帧：帧间灰度均差 `≥thr` 保留，超 `max-frames` 取分数最高者。

## FAIL
| 现象 | 原因 | 动作 |
|---|---|---|
| `err:need_pid` | 未给 `--pid` | `ctxinject.py hosts` 取 PID |
| `err:too_long` | 超 `--max-sec` | 显式调大（先算帧数） |
| `err:missing_bin:ffmpeg` | 依赖缺 | `pkg install ffmpeg` / `pip install yt-dlp` |
| `err:no_video_stream` | 纯音频/损坏 | 换输入 |
| `exit 4` | `got<want` | 看 `stderr`；帧路径可能含空格 |
| `exit 5` | 全空场 | `--thr 8~12` 或按秒定点抽帧 |
| `exit 3` | 宿主跑 RUN | 正常，读 watch log，勿重跑 |
| 帧太多 | 阈值过松 | `--thr 8~12` 或 `--max-frames 8` |
| 小字不清 | 宿主 512 封顶 | 裁 ROI 单独注入 |

## RULE
- 注入时 `--pid` 必填（与 ctxinject 同口径），勿省。
- 一次 `videowatch` 至多 1 条 user 消息。
- `--long` >512 无收益；帧数只用 `--max-frames` 控。
- 产物落 `~/.cache`；路径禁含空格。
