# ctxinject — 向活跃宿主追加一条消息

SCRIPT `~/.config/term_agent/skill/ctxinject.py`（182 行）
SEMANTICS 向目标进程 `mem_hist` 末尾**追加** 1 条 `role=user`。无删/改/回滚能力，永久不做。
REF `memory/运行时注入-sys.remote_exec实测.md`（机制与实测）

## TRIGGER
| 条件 | 动作 |
|---|---|
| 结论依赖画面/图像内容 | `auto` |
| 有图片需进推理 | `inject` |
| `cat/ls/grep/df` 可得 | 禁用，用命令 |
| 仅查宿主存活/PID | `hosts` |
| 上次返回 `3` | 禁用重跑，读 watch log |
| 图仅存档不求推理 | 禁用，存盘 |

## CMD
```bash
S=~/.config/term_agent/skill/ctxinject.py
python3 $S hosts                                              # → pid 列表
python3 $S auto   --pid PID                                   # 截屏+注入+唤醒
python3 $S inject --pid PID -w "text" /abs/a.png /abs/b.png    # N 图 1 条消息
python3 $S inject --pid PID "text"                            # 纯文本
python3 $S shot   -o /abs/x.png [--device 127.0.0.1:7957] [--long N]
python3 $S gc
```
取 PID：
```bash
python3 $S hosts | python3 -c 'import sys,json;print("\n".join(str(p) for p,_ in json.load(sys.stdin)["list"]))'
```

## ARG
| 子命令 | 参数 | 默认 | 约束 |
|---|---|---|---|
| `hosts` | `--mark` | `term_agent.py` | cmdline 文件名匹配 |
| `shot` | `-o` | `~/.cache/ctxinject/shot_<ts>.png` | 目录须存在或可建 |
| | `--device` | `127.0.0.1:7957` | 不在在线列表则取首台 |
| | `--long` | 无 | 长边；>512 无收益（宿主再压） |
| `inject` | `items` | — | 后缀∈`.png/.jpg/.jpeg/.gif/.webp` 者为图，余按序拼文本 |
| | `--pid` | required | 缺→`2` |
| | `-w/--wake` | off | `SIGWINCH`；目标未捕获→`note.no_sigwinch` 且转排队 |
| | `--timeout` | `8.0` | 无 `-w` 时实际 `min(timeout,2)` |
| `auto` | `--text` | `看图` | 附图文本 |
| | `--pid` / `--timeout` | required / `8.0` | 同 inject |

## EXIT
| 码 | 含义 | 动作 |
|---|---|---|
| `0` | 已落地 | 读 `ev:ok` |
| `1` | 参数/环境错 | 读 stderr `ev:err`；`msg` 见 FAIL |
| `2` | argparse 拒绝（缺 `--pid`） | 补 `--pid` |
| `3` | 已排队 | 停手 → WAIT |

## EV（stdout 单行 JSON；containers compact）
| ev | 字段 | 含义 |
|---|---|---|
| `hosts` | `list:[[pid,cmdline]]` | 候选宿主 |
| `shot` | `path,bytes` | 截图产物 |
| `gc` | `n` | 清理数 |
| `ok` | `el,d` | 已落地；`d.hist_len` / `d.content` / `d.imgs` / `d.img` / `d.skip` |
| `defer` | `el,reason,d` | `reason∈busy,no_checkpoint`；`d:null`=未到检查点 |
| `note` | `msg,mode` | `msg=no_sigwinch` → 已转排队 |
| `watch_spawn` | `log` | 看守日志路径 |
| `watch_ok` | `t,d` | 补插成功 |
| `watch_timeout` | `t` | 600s 放弃 |
| `watch_err` | `t,msg` | 目标消失等 |
| `err`(stderr) | `msg` | 见 FAIL |

判读 `d.content`：`[["text",s],["image_url",n]]`；`n`=base64 字符数，`>3000` 才算真有图。

## WAIT（`exit 3` 后唯一动作）
```bash
L=~/.cache/ctxinject/watch_PID.log
for i in $(seq 120); do grep -qE '"ev":"(watch_ok|watch_timeout|watch_err)"' "$L" 2>/dev/null && break; sleep 5; done; tail -1 "$L"
```
看守节奏 2s×10 → 10s，上限 600s。停止看守：按 pid `kill`。禁用 `pkill -f 'ctxinject.py watch'`（匹配自身 shell → 自杀）。

## FAIL
| `msg` / 现象 | 原因 | 动作 |
|---|---|---|
| `no_such_pid:N` | pid 不存在 | 重取 PID |
| `target_is_self` | 指向本进程 | 换 PID |
| `no_such_image:P` | 路径不存在/含空格被切 | 绝对路径、无空格 |
| `no_such_file` / `no_adb_device` | adb 未就绪 | `adb devices` |
| `screencap_not_png` | 截屏失败 | 点亮屏幕重试 |
| `cmd_fail` / `remote_exec 失败` | 解释器不匹配/目标已退 | 同 UID + 同 CPython 3.14 小版本 |
| `defer.reason=busy` | 宿主在跑 RUN | 正常，走 WAIT，勿重跑 |
| `d.skip=dup` | 同 token 已落地 | 视为成功 |
| 图被当文本 | 后缀不在白名单 | 转 `.png` |
| `hist_len` +2 | 曾重跑 | 不可撤回 |

## RULE
- 注入 = 在运行中进程执行任意代码 → 需用户显式授权后执行。
- 前提：同 UID + 完全相同的 CPython 解释器。
- `SIGWINCH` 打断宿主当前行输入（提示符重绘，可能吞半行）。
- 历史只追加、0 变动：无 `drop`，不新增任何删除/改写能力。
- 自测用假宿主，用完 `kill`。

## COST
| 项 | 效应 |
|---|---|
| 每条注入 | `hist_len` +1，一条 user 消息，**不可撤回** |
| 压缩边界 | 该条成为新 `last_u` → 下次 `compress()` 作用于其之前全部历史 |
| 图寿命 | 活到下一次压缩，之后送模型为 `[图]` |
| 缓存 | 每次留 `payloads/pl_*`、`rc_*`；`gc` 仅清 >3 天；`shot_*.png` 不清 |

## NOT-EXIST
| 需求 | 替代 |
|---|---|
| probe（只读查历史） | 仅能从上一次回执 `hist_len` 推断 |
| drop（删已注入消息） | 无。永久不做 |
| wait 子命令 | WAIT 段 shell 循环 |
