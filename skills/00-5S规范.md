# 5S 规范

SCOPE `memory/` `skill/` `taskbook/` 及各自 `archive/`
SELF 本文即样例：表优先、零散文、禁 emoji 分组、禁变更史、禁导读
CHECK `python3 ~/.config/term_agent/skill/5s_check.py` → JSON，`findings` 非空即不合格
AUDIENCE agent 检索与判断，非人类阅读

## NECESSITY
| 事实 | 后果 |
|---|---|
| 索引曾 3 组重复 + 15 条无表头裸行 + 11 条漏收 | 按索引找不到 → 退回 `ls` 逐个猜，浪费整轮 |
| 12 篇高活跃文档 94.7KB → 39.0KB（-59%） | 过程记录挤占上下文；读完才知无结论 |
| 同一坑在 4 篇各写一遍（包名不可信 / logcat 不可用 / 截图小≠失败 / ping 不可信） | 改一处漏三处 → 记忆互相矛盾 |
| 旧记"云端差异 16 行"，实测 7 行 | 错误数字被当事实复用 → 直接推错 |
| 合并式文档正文 30 行 + 附录全文 200 行 | 归档件内容重复一遍，双份维护 |

结论：不做 5S 的代价不是"乱"，是**给出错误结论**。

## TYPE（三类边界）
| 目录 | 只写 | 禁写 | 建立时机 |
|---|---|---|---|
| `memory/` | 确定事实、数字、坑、可复用命令 | 操作步骤 | 结论稳定后 |
| `skill/` | 何时用 / 命令 / 参数 / 退出码 / 失败处置 | 实测数据、成本口径、复盘、算法推导 | 做法验证后 |
| `taskbook/` | 过程、证据、遗留项 | 结论（结论进 memory） | 任务开始即建 |

跨类引用只写一行 `REF <路径>`，不复制内容。

## DOC（单篇规格）
顺序固定，缺项可省，不得乱序：
```
H1 标题
元信息行（大写键，见下表）
FACTS / CMD / ARG / EXIT / EV / FAIL / TRAPS / RULE / COST / REF
```

| 元信息键 | 值 |
|---|---|
| `STATE` | `✓ 日期` 或 `⚠ 已失效（原因）` |
| `SCOPE` | 一句话边界，禁形容 |
| `SCRIPT` `CMD` | 可 `cat` / 可执行的路径 |
| `REF` | 关联文档路径 |

| 禁用 | 原因 |
|---|---|
| 散文段、第一人称、"一句话导读" | 占预算，无可执行信息 |
| emoji 分组标题、分隔线装饰 | 无检索价值 |
| 变更史 / "已改过三次" | 交 git log |
| 原文附录（已归档件的副本） | 双份维护，必分叉 |
| 无数字的形容词（更清晰/更快/更稳） | 不可验证 |
| 表格内含 `|` 未转义 | 破表 |

篇幅：`skill/*.md` ≤8 KB；`memory/*.md` ≤8 KB；`00-索引.md` ≤6 KB。超限 → 拆或裁（裁附录副本优先）。

## INDEX（`00-索引.md`）
四列固定，脚本单列（`—` 表示无）：
| 技能 md | 脚本 | 触发 | 要点 |
|---|---|---|---|
| 文件（可 `cat`）| 同名脚本 | 关键词 / 症状 / 任务类型 | 可执行结论或关键数字 |

约束：一文件一行，禁重复行；触发列决定"该不该读"；要点列 ≤1 行，禁"见文"；退役项标 ⚠ 并移 `archive/`。

必写：`READ` 读法行 + `MARK` 图例（★现行 / ⚠已失效 / 无标背景）。
新增或改名文件**必须**同步索引，否则 CHECK 报漏收。

## NAME
| 类型 | 规则 |
|---|---|
| memory / skill | 主题名，禁日期前缀（日期进正文 `STATE`） |
| taskbook | `任务名vX.Y.md`；改动版本 +1 |
| 结项 | `-eol.md` |
| 被取代 | `-superseded.md`（保留低版本，不删） |
| 备份 | `<原名>.bak_YYYYmmdd_HHMMSS`（跟主文件原位，供回滚） |

## ARCHIVE
| 对象 | 去向 |
|---|---|
| 结项任务书、非近期 eol | `taskbook/archive/`（保持原文件名） |
| 被合并原件、`.bak_*`、旧索引 | 各目录 `archive/` |
| 空件 / 陈旧演练件 | `archive/5s-<日期>/` |
| 运行态（`.tavily_state`、`.tmp`） | 原位不动 |

移动不删除。用户明确声明的内容不 recycle；不确定 → 原位。

## STEPS
| 步 | 动作 | 判据 |
|---|---|---|
| 1 整理 | 列全量 + mtime + 体量，标失效/空件/重复 | 每件有归属 |
| 2 整顿 | 索引补漏去重，改三列体例 | `5s_check.py` 0 findings |
| 3 清洁 | 删附录副本、合并重复坑、改正过期数字 | 无重复段落 |
| 4 标准化 | 命名/后缀/元信息/篇幅对齐本文 | NAME 表逐项通过 |
| 5 素养 | 新文件即补索引；改输出格式先 `grep` 消费者 | 下次 CHECK 通过 |

## CHECK
```bash
python3 ~/.config/term_agent/skill/5s_check.py            # 全仓
python3 ~/.config/term_agent/skill/5s_check.py memory     # 单目录
```
检出项：索引漏收 / 索引重复行 / 0 字节件 / `archive/` 无后缀件 / 超长散文行 / 缺 H2 结构 / 表格竖线未转义。

## TRAPS
| 现象 | 原因 | 处置 |
|---|---|---|
| `git push` 判 rc 恒 0 | `cmd \| sed; echo $?` 取的是 sed | 重定向文件后单独取 |
| 批量移动后总数变少 | `mv` 覆盖同名 | 先查重名再移 |
| 索引校验"零漏"但实际缺 | 用 `${f%.md}` 模糊匹配，`a` 命中 `ab` | 匹配行首 `| <名>` |
| 改格式打挂调用方 | 输出契约变更未搜消费者 | `grep -rn '旧格式串' skill/` |
| 前缀 `/tmp` 写失败 | Termux 无 `/tmp` 写权限 | `$HOME/.cache/` |
