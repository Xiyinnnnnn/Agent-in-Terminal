# 工作交接-执行轨迹
STATE ✓ 2026-11-17｜SCOPE 另一个 agent 的 `mem_hist`+`summaries` → 结构化轨迹｜SCRIPT `trace.py`

## 何时用
| 判据 | 说明 |
|---|---|
| 接着干别人做了一半的活 | 先骨架后细节，不读原文 |
| 历史太大，整份喂进来会撑爆 | 26.8KB / 7704 tok → L0 308、L1 1395 |
| 要知道上一个人崩在哪一步 | `--fails` 一次列全，排最前 |
| 要前史因果（为什么选这条路） | `--sums` 取摘要链全文 |
| 交接单要贴进任务书 | `--md` 出 5 列步骤表 |

## 命令
```bash
T=~/.config/term_agent/skill/trace.py
python3 $T --pid 1234                  # 在线导出+清洗，一步到位
python3 $T --pid 1234 --level 0        # 只要骨架
python3 $T --pid 1234 --fails          # 只看失败清单
python3 $T --pid 1234 --md > 交接.md   # 可直接贴 taskbook 的表
python3 $T hist.json --sums            # 摘要链全文（因果）
python3 $T hist.json --sum 3           # 单条摘要
python3 $T hist.json --id '#3.2'       # 单条工具完整原文
python3 $T hist.json --grep 'Failed'   # 正则回捞，只付命中部分
python3 $T --selftest                  # 8 项自检
```

## 三层分工
| 档 | 内容 |
|---|---|
| L0 `--level 0` | 一轮一行：意图 + 工具数 + 失败数 |
| L1（默认） | 每工具一行：解释 + 命令 + `exit N · 行数/字节 · 首行` |
| L2 `--id`/`--grep` | 命中条目完整 stdout/stderr，按需付 |

省量数据：REF `memory/Termux-跨进程读终端输出与跨agent上下文.md`「轨迹清洗省量实测」节

## 参数 / 退出码
| 参数 | 默认 | 说明 |
|---|---|---|
| `--pid` | 无 | 在线导出；同 UID + 同 CPython 3.14；**须用户授权** |
| `--level` | 1 | 0=骨架 1=轨迹 |
| `--budget` | 0 | token 预算，超则自动降 L0 |
| `--sums` `--sum N` | 无 | 摘要链全文 / 单条 |
| `--id` `--grep` | 无 | 精确回捞，坐标取自 L1 输出 |
| `--md` `--fails` | 关 | 任务书表格 / 失败清单 |

退出码：`0` 成功｜`1` 用法错｜`2` 目标不存在或注入失败｜`3` 空历史

## 与 taskbook 搭配
| 交接环节 | 命令 | 落点 |
|---|---|---|
| 全局骨架 | `--level 0` | 任务书「前史」段 |
| 已做/未做 | `--md` | 任务书步骤表（5 列，规范允许） |
| 崩过的地方 | `--fails` | 任务书「坑」段 |
| 因果与决策 | `--sums` | 任务书「为什么这样选」 |

## 陷阱
| 现象 | 原因 | 处置 |
|---|---|---|
| `PyRuntime address lookup failed` | 目标已退出或不是 CPython 3.14 | `/proc/<pid>` 是否存在；换落盘文件路径 |
| 摘要全丢 | 只读了 `mem_hist` | 摘要存在 `summaries` 变量，`trace.py` 已同时取 |
| 摘要对不上轮次 | 压缩时未记录覆盖范围 | 摘要自身无边界，只能读文字判断 |
| 坐标 `#1.1` 找不到 | 用了 `--level 0` | 骨架不输出工具坐标，回 L1 取 |
| 目标正在跑长命令，注入迟迟不落盘 | 目标在 subprocess 读循环里没回到解释器 | 等它一轮结束再取，`--pid` 默认等 5s |
| 结果体积暴涨 | 搬运了工具原文 | 只走 L1 四元组；原文用 `--grep` 按需 |

## 机制（写死，不要改）
| 事实 | 依据 |
|---|---|
| `mem_hist` 无时间戳 | 唯一时间轴 = `#轮次.工具序` |
| 工具轨迹本就在 `mem_hist` | `assistant.tool_calls` + `role=tool` 成对 |
| 摘要链递进滚动 | 新摘要 = 旧摘要 + 新历史重总结；末条最全，前条是防漂移对照 |
| 摘要链禁排序/合并/去重 | 去重即删掉漂移证据 |
| `compress()` 后旧轨迹永久消失 | `mem_hist = mem_hist[last_u:]`，故须压缩前取 |
