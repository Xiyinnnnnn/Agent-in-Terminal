# 文档规范

STATE ✓ 2026-10-27｜SCOPE `memory/` `skill/` `taskbook/` 及各自 `archive/`
SCRIPT `~/.config/term_agent/skill/5s_check.py`
CHECK_CMD `python3 ~/.config/term_agent/skill/5s_check.py` → JSON，`errors` 非 0 即不合格（`warn` 不计）
SELF 本文即样例：表优先、零散文、禁 emoji 分组、禁变更史、禁导读
AUDIENCE 只服务 agent 的检索与判断，不服务人类阅读
WHY 跳过本规范的代价不是"乱"，是复用错误数字与过期做法

## 分区（三类文档，三套规格）
| 目录 | 只写 | 禁写 | 建立时机 |
|---|---|---|---|
| `memory/` | 结论、数字、坑、理由 | 操作步骤、过程复盘 | 结论稳定后 |
| `skill/` | 何时用、命令、参数、失败处置 | 实测数据、推导、复盘 | 做法验证后 |
| `taskbook/` | 过程、证据、遗留项 | 结论 | 任务开始即建 |

同一含义只存一处：数据在 memory，skill 与任务书只写 `REF <路径>` 一行。
指针只挂一层：`REF` 指向的文件内不得再有 `REF`，否则到达要多次跳转。

## 通用八条（三类共用）
| # | 规则 | 判据 |
|---|---|---|
| 1 | 一行一谓词 | 同列不同质即拆表 |
| 2 | no-op 整句删 | 删后行为不变 → 删整句，不修词 |
| 3 | 正向写 | 写目标行为；禁令只用于硬红线并配「应做 X」 |
| 4 | 单源 | 同一含义全文仅一处 |
| 5 | 判据可校验且穷尽 | 能命令验证，禁「理解到位」 |
| 6 | 只缓存查不到的 | 配置/`--help`/目录能查到的不写；理由与坑必留 |
| 7 | 表 ≤4 列、行长 ≤240 | 窄终端换行即读断 |
| 8 | 命令进代码块 | 可粘即跑，禁裸文本 |

## 记忆 `memory/`
一条记忆 = 一个可独立 `cat` 使用的结论集。

```markdown
# 主题名
STATE ✓ 日期｜SCOPE 一句边界
## 结论
| 项 | 值 | 验证 |
## 坑 / 失效条件
| 现象 | 原因 | 处置 |
## SRC
论文 / 链接 / 文件路径
```

| 规则 | 值 |
|---|---|
| 数字必须带口径 | 测量条件、样本量、版本；无口径的数字视为噪声 |
| 结论可反驳 | 写明失效条件：何时这条不再成立 |
| 只写查不到的 | 配置能读到的、`--help` 能打的不进记忆 |
| 篇幅 | 硬 24 KB / 软 14 KB；超限按主题拆，不删证据 |
| 命名 | 主题名；禁日期前缀，日期进 `STATE` |

## 技能 `skill/`
读者是正要动手的 agent，只写怎么做。

```markdown
# 技能名
STATE ✓ 日期｜SCOPE 一句边界｜SCRIPT 脚本名.py
## 何时用
## 命令
## 参数 / 退出码
## 失败处置
## 陷阱
```

| 规则 | 值 |
|---|---|
| 篇幅 | 操作型 ≤50 行；规范/索引类走定名章节，只受 10 KB 硬限 |
| 触发即产品 | 索引「触发」列决定选不选中：写症状与原话词，禁泛描述 |
| 命令单源 | 用法只在 `## 命令` 出现，不散落到正文 |
| 脚本同目录 | `skill/同名.py/.sh`，文档给路径与参数，不贴实现 |
| 命名 | `00-` 前缀 = 高频/基础件，因 `0` < 中文排最前；其余用主题名 |

## 任务书 `taskbook/`
读者是下一棒 agent，只写过程与证据；结论一律外流到 memory。

```markdown
# 任务名vX.Y
STATE 进行中 日期｜REF memory/结论.md
## 目标
## 步骤
| # | 动作 | 判据 | 状态 | 证据 |
## 遗留
| 项 | 原因 | 下一步 |
```

| 规则 | 值 |
|---|---|
| 状态就地改 | 每完成一节点 `[ ]`→`[x]` + 证据（输出/行数/哈希），不攒到最后 |
| 版本即文件名 | 改动 → 版本 +1；结项 → `-eol.md` 移 `archive/` |
| 结论外流 | 全绿后要点搬进 memory，本篇只留 `REF` |
| 篇幅 | 硬 24 KB / 软 12 KB |
| 命名 | `任务名vX.Y.md`；`-eol` = 结项 |

## 索引 `00-索引.md`
| 目录 | 列 |
|---|---|
| `skill/` | 技能 md ｜ 脚本 ｜ 触发 ｜ 要点 |
| `memory/` | 文件 ｜ 触发 ｜ 结论 |
| `taskbook/` | 任务书 ｜ 主题 ｜ 状态 |

| 约束 | 值 |
|---|---|
| 首列 | 文件名，可 `cat`，与磁盘一致 |
| 触发列 | 关键词 / 症状 / 任务类型，决定"该不该读" |
| 末列 | 可执行结论或关键数字，≤1 行，禁"见文" |
| 行数 | 一文件一行，禁重复行 |
| 必写 | `READ` 读法行 + `MARK` 图例（★现行 / `-dep` 已废弃 / 无标 = 背景） |
| 同步 | 新增或改名必须同批改索引，否则 CHECK 报 `index_missing` |

## 命名
| 类型 | 规则 |
|---|---|
| memory / skill | 主题名；日期只进正文 `STATE` |
| taskbook | `任务名vX.Y.md`，改动 +1 |
| 结项 | `-eol.md` |
| 废弃 / 失效 | 加 `-dep` 后缀（全小写），保留原位 |
| 备份 | `<原名>.bak_YYYYmmdd_HHMMSS`，跟主文件原位 |

## 归档
| 对象 | 去向 |
|---|---|
| 结项任务书、非近期 eol | `taskbook/archive/` |
| 被合并原件、`.bak_*`、旧索引 | 各目录 `archive/` |
| 空件 / 陈旧演练件 | `archive/5s-<日期>/` |
| 运行态（`.tmp`、`.*_state`） | 原位不动 |

移动不删除。用户明确声明的内容不回收；不确定 → 原位。

## 流程
| 步 | 动作 | 判据 |
|---|---|---|
| 1 盘点 | 列全量 + mtime + 体量，标失效/空件/重复 | 每件有归属 |
| 2 整顿 | 索引补漏去重，保持各目录列体例 | `5s_check.py` errors=0 |
| 3 清洁 | 删附录副本、合并重复坑、改正过期数字 | 无重复段落 |
| 4 标准化 | 命名/后缀/元信息/篇幅对齐本文 | 命名表逐项通过 |
| 5 习惯 | 新文件即补索引；改输出格式先 grep 消费者 | 下次 CHECK 通过 |

## 校验
```bash
python3 ~/.config/term_agent/skill/5s_check.py            # 全仓
python3 ~/.config/term_agent/skill/5s_check.py memory     # 单目录
```
| 类别 | 项 |
|---|---|
| error | `index_missing` 索引漏收 ｜ `index_dup` 重复行 ｜ `empty_file` <100 B ｜ `no_h2` 缺结构 ｜ `table_cols` 竖线不齐 ｜ `too_big` 超硬限 ｜ `index_too_big` |
| warn | `near_limit` 超软限 ｜ `index_near_limit` ｜ `long_line` >240 字符 |

脚本只验形状，不验信息量。下列三条只能人工过，交付前逐条勾：
| 人工门 | 判据 |
|---|---|
| no-op | 每句自问"删了行为会变吗"，不变即删 |
| 单源 | 同一数字/结论全文 `grep` 只应命中一处 |
| 指针 | 每个 `REF` 有触发词，且目标文件内无 `REF` |

`archive/` 不检后缀——目录本身即归档标记。

## 陷阱
| 现象 | 原因 | 处置 |
|---|---|---|
| `git push` 判 rc 恒 0 | `cmd \| sed; echo $?` 取的是 sed | 重定向文件后单独取 |
| 批量移动后总数变少 | `mv` 覆盖同名 | 先查重名再移 |
| 索引校验"零漏"但实际缺 | 模糊匹配 `a` 命中 `ab` | 匹配行首 `| <名>` |
| 改格式打挂调用方 | 输出契约变更未搜消费者 | `grep -rn '旧格式串' skill/` |
| 前缀 `/tmp` 写失败 | Termux 无 `/tmp` 写权限 | 用 `$HOME/.cache/` |
