# 疑难升级-大模型一次性诊断
STATE ✓ 2026-11-17｜SCOPE 小模型受阻后把八段交接 one shot 送 Kimi-K3.1-Pro｜SCRIPT escalate.py｜COST 单次按 $0.5 计｜GATE 脚本即发送，先取授权｜REF `memory/Kimi-K3.1-Pro-one-shot成本与参数.md`

## 何时用
| 条件 | 动作 |
|---|---|
| 同错 3 次未解、2 种方案失败、关键校验持续失败 | 生成交接 |
| 一次命令或一次查文档能解 | 不升级，自解 |
| 决定升级后 | 顺序固定：先 `grep` `memory/` 与 `skill/` 命中即用 → 汇总八段并在正文贴全文取授权 → 原样执行一次，按 `[STEP]`/`[IF]` 验证 |

## 命令
```bash
S=~/.config/term_agent/skill/escalate.py
python3 $S -h                    # 打印用法 + 八段模板
python3 $S <<'EOF'               # 发送（high）；疑难档在 $S 后加 max
[GOAL] …
（其余七段按模板，[ASK] 必填）
EOF
```

## 参数 / 退出码
| 项 | 值 | 说明 |
|---|---|---|
| 模型 | `moonshotai/Kimi-K3.1-Pro` | 写死；换模型改脚本 `MODEL` 行 |
| 档位 | `high` / `max` | 输出预算 8192 / 16384，透传 `reasoning_effort` |
| 成本 | $0.5 / 次 | 预算口径；实测值见 REF，不在此重复 |

码：`0` 正常｜`1` 缺段/档位错/空返回｜异常=消息含 HTTP 码或「连不上」

## 失败处置
| 现象 | 处置 |
|---|---|
| 连不上 3050 | 起 `~/commandcode-proxy` 后重跑 |
| HTTP 401 | key 无效或换机后 machine-id 变 → 重生成 key.bin |
| HTTP 400 | 模型 ID 拼写 / 档位值不被接受 |
| 空返回 | 看 `completion_tokens` 是否被思考链吃满 → 升档，或改脚本降预算 |

## 陷阱
| 现象 | 原因 | 处置 |
|---|---|---|
| `缺必需段 [GOAL] [ASK]` | heredoc 未生效或内容为空 | 用 `<<'EOF'` 引号形式，避免变量展开 |
| 交接很长 | 混入历史、推理、无关输出 | 只留能改变判断的事实 |
| 重复已失败方案 | `[TRIED]` 只写动作不写结果 | 每条写成 动作 → 实际结果 |
| 未授权先发 | 把执行脚本当成预览 | 脚本即发送，第 2 步不可跳 |
