# 看文档
STATE ✓ 2026-11-17｜SCOPE 二进制/半结构化文件 → 可读 md；不含音频转录与老 `.doc`｜SCRIPT `md2md.py`

## 何时用
拿到 pdf/docx/xlsx/pptx/html/epub/ipynb/zip/图片，或要读网页正文 → 先转 md 再推理；直接 `cat` 只见乱码或空串时同用。

## 命令
```bash
md2md 文件                     # stdout
md2md 文件 -o out.md
md2md 目录 -o 输出目录         # 递归批量，产物 = 原名+.md（a.csv→a.csv.md）
md2md https://example.com      # URL 直读（网页/YouTube/Wikipedia）
md2md -                        # stdin 直读，可接 curl / pdftotext
```
```python
from markitdown import MarkItDown
MarkItDown(enable_plugins=False).convert("a.pdf").markdown
```

## 参数 / 退出码
| 参数 | 行为 |
|---|---|
| `-o` | 单文件→写该路径；目录→输出根；目录缺省落 `./md_out` |
| `--plain` | 放开 onnxruntime 的 android 警告（调试用） |
| 退出码 | 0 成功 ｜ 1 转换失败（stderr 带 `CONVERT FAILED: <名>: <原因>`）｜ 2 路径不存在 |
| 批量 | 末行 `done: ok=N fail=M out=<目录>` 走 stderr；有失败仍返回 1 |

## 失败处置
| 报错 / 症状 | 处置 |
|---|---|
| `MissingDependency` 出自 xlsx/xls | 无需装 pandas：自研 `OpenpyxlXlsxConverter`/`XlrdXlsConverter` 已接管（priority 0.0） |
| 图片转出空串 | 内置 `ImageConverter` 依赖 exiftool；`PillowImageConverter`（priority -0.5）已覆盖 |
| docx/pdf/pptx 报缺依赖 | `python3 -m pip install "markitdown[docx,pdf,pptx]"` |
| 依赖需重装 | 顺序不可换：先 `pkg install -y python-numpy python-lxml python-pillow python-onnxruntime python-cryptography libc++`，再 pip |

## 陷阱
| 现象 | 原因 | 处置 |
|---|---|---|
| numpy 导入崩 `cannot locate symbol __hash_memory` | libc++ 29 缺符号 | `pkg install libc++`（→30），不必重装 numpy |
| 装 `markitdown[all]` 多 100 MB+ | 连带 azure-ai-* 全家桶 | 只装 `[docx,pdf,pptx]` |
| 批量出现同名覆盖 | `a.csv` 与 `a.docx` 都出 `a.md` | 已改「原名+`.md`」，勿改回 |
| `.doc`/`.rtf` 出乱码 | 无真解析器，按纯文本吐 | 先 `libreoffice --headless --convert-to docx` 再转 |
| 音频/YouTube 报缺 pydub | 缺 pydub+speechrecognition+ffmpeg | 转用 `00-看视频-抽帧注入上下文` |
