# 看视频-抽帧注入上下文
STATE ✓ 2026-11-17｜SCOPE 视频/链接 → 有序帧 或 `[mm:ss]` 字幕 → 上下文｜SCRIPT `videowatch.py`｜REF `memory/看视频字幕-提取与去重实测.md`

## 何时用
- 问「有没有字幕 / 字幕讲了什么 / 台词原文」→ 先 `subs`，有字幕就不必抽帧
- 问「这段画面是什么 / 第几分钟出现 X」→ 抽帧
- 已有截图看不清，需多帧对照

## 命令
```bash
V=~/.config/term_agent/skill/videowatch.py
python3 $V subs "<URL 或本地路径>"           # 只取字幕 → md；stdout 回路径/语言/行数/头 6 行
python3 $V subs x.mp4 --langs "zh-Hans,en"   # 语言优先级；本地文件忽略此参数
python3 $V "<URL 或本地路径>" --pid PID      # 抽帧并注入活跃上下文
python3 $V /abs/x.mp4 --no-inject            # 只出图，不注入
```

## 参数 / 退出码
| 参数 | 默认 | 说明 |
|---|---|---|
| `subs` | — | 字幕模式：不出帧、不注入，`--pid` 无效 |
| `--langs` | `zh-Hans,zh-CN,zh,en` | 传 yt-dlp `--sub-langs`；`all` 放开全部 |
| `--pid` | 无 | 注入必填；缺 → `err:need_pid`；`--no-inject` 可省 |
| `--thr` / `--max-frames` | 6.0 / 16 | 灰度均差阈值 / 硬上限，超限按分数取 top-N |
| `--long` / `--max-sec` | 480 / 900 | 帧长边 / 时长闸门，超则 `err:too_long` |
| `--no-inject` / `--quiet` | off | 只出图 / 不唤醒宿主（排队） |
| 码 | — | `0` 成功 ｜ `1` 依赖参数错 ｜ `3` 已排队 ｜ `4` 落地≠应注入 ｜ `5` 全空场 ｜ `6` 无字幕 |

## 失败处置
| 现象 | 原因 | 动作 |
|---|---|---|
| `exit 6` | 无内嵌轨、无外挂件、平台无字幕 | 回退抽帧；或 `--langs all` 再试一次 |
| `err:missing_bin:yt-dlp` | 缺 yt-dlp | `pip install yt-dlp` |
| `err:missing_bin:ffmpeg` | 缺 ffmpeg/ffprobe | Termux `pkg install ffmpeg`；Debian 系 `apt install ffmpeg` |
| `err:need_pid` | 抽帧未给 PID | `ctxinject.py hosts` 取 |
| `err:too_long` | 超 `--max-sec` | 显式调大（先算帧数） |
| `exit 4` / `5` | `got<want` / 全空场 | 先看 stderr；`--thr 8~12` 或按秒定点抽帧 |

## 陷阱
- `subs` 只跑 `--skip-download --write-subs --write-auto-subs`，不下视频；产物 `~/.cache/videowatch/<sha1>/subs/<lang>.md`，原始件在 `subs_raw/`。
- 自动字幕滚动重复按「同开始时间取最长 + 子串包含」去重，不保证一句一行；断句以 `[mm:ss]` 行为准。
- 本地优先内嵌轨（ffprobe 查 `s` 流），无则扫同目录 `<视频名>.<语言>.srt|vtt|ass`；`.ass/.ssa` 经 ffmpeg 转 srt。
- mp4 的 `mov_text` 常无 `language` 标签 → 落 `und.md`（多轨 `und0/und1`），别按文件名猜语言。
- 抽帧产物在 `<sha1>/out/`，报时间读 `manifest.json` 的 `sec`，别解文件名。
- 小字不清是宿主 512 封顶所致 → 裁 ROI 单帧注入，别放大整帧；帧太多 = `--thr` 过松。
