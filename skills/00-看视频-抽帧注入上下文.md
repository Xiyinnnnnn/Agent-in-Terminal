# 看视频-抽帧注入上下文
STATE ✓ 2026-10-24｜SCOPE 视频 → 有序时间戳帧 → 活跃上下文｜SCRIPT `videowatch.py`｜REF `memory/archive/视频抽帧-1fps变帧检测与注入实测.md`
## 何时用
- 视频里问「这段画面是什么 / 第几分钟出现 X / 有没有字幕」
- 要的是有序带时间戳的帧，不是整段视频
- 已有截图看不清，需要多帧对照
## 命令
```bash
V=~/.config/term_agent/skill/videowatch.py
python3 $V "<URL 或本地路径>" --pid PID     # 抽帧并注入活跃上下文
python3 $V /abs/x.mp4 --no-inject           # 只出图，不注入
```
## 参数 / 退出码
| 参数 | 默认 | 说明 |
|---|---|---|
| `--pid` | 无 | 注入必填；缺 → `err:need_pid`；`--no-inject` 可省 |
| `--thr` | 6.0 | 灰度均差阈值 0–255，调大只留大变化 |
| `--max-frames` | 16 | 硬上限，超限按分数保序取 top-N |
| `--long` | 480 | 帧长边；>512 无收益（宿主再压） |
| `--max-sec` | 900 | 时长闸门，超则 `err:too_long` |
| `--no-inject` / `--quiet` | off | 只出图 / 不唤醒宿主（排队） |
| 码 | — | `0` 落地 ｜ `1` 参数依赖错 ｜ `3` 已排队 ｜ `4` 落地数≠应注入数 ｜ `5` 全空场未注入 |
## 失败处置
| 现象 | 原因 | 动作 |
|---|---|---|
| `err:need_pid` | 未给 PID | `ctxinject.py hosts` 取 |
| `err:missing_bin:ffmpeg` | 依赖缺 | Termux `pkg install ffmpeg` / Debian 系 `apt install ffmpeg`；yt-dlp 用 `pip install yt-dlp` |
| `err:too_long` | 超 `--max-sec` | 显式调大（先算帧数） |
| `exit 4` | `got<want` | 看 stderr；路径禁含空格 |
| `exit 5` | 全空场 | `--thr 8~12` 或按秒定点抽帧 |
| `exit 3` | 宿主正跑 RUN | 正常，读 watch log，勿重跑 |
## 陷阱
- 产物落 `~/.cache/videowatch/<sha1[:10]>/`，报时间读 `manifest.json` 的 `sec`，别解文件名。
- 注入时 `--pid` 必填，与 `ctxinject.py` 同口径，勿省。
- 一次调用至多产生 1 条 user 消息；帧数只用 `--max-frames` 控，别改 `--long`。
- 小字不清是宿主 512 封顶所致 → 裁 ROI 单帧注入，别放大整帧。
- 帧太多 = 阈值过松，`--thr 8~12`。
