# 联网搜索（Tavily 四账号池）
STATE ✓ 2026-10-24｜SCOPE Tavily Search API 的查询与吞吐；不含 crawl/extract/map｜SCRIPT `search.py`
## 何时用
- 要查网上资料、比价、找文档、确认 API 用法，且本机直连拿不到
- 一次要搜 10 条以上（批量并发）
- 撞 429，或要确认各 key 还剩多少额度与冷却
## 命令
```bash
cd ~/.config/cli-agent/skill
./search.py "query"                          # 默认 basic / 5 条
./search.py "query" -m 10 -d advanced -a -s  # 深度 + LLM 答案 + 摘要
./search.py -q qs.txt -m 3 -j                # 批量并发，输出 JSON
./search.py --stats                          # 各账号剩余额度/窗口/冷却
./search.py --reset                          # 清冷却与失败计数
./search.py --refresh-quota --stats          # 强制刷 /usage
```
## 参数 / 退出码
| 参数 | 默认 | 说明 |
|---|---|---|
| `query` / `-q 文件` | — | 多条即并发，文件每行一条 |
| `-d` | basic | `basic` `advanced` `fast` `ultra-fast` |
| `-m` | 5 | 1–20 |
| `-t` / `-r` | general / 空 | 类型 / 时间窗 `day week month year` |
| `-a` `-s` `-j` `-v` | 关 | 答案 / 摘要 / 原始 JSON / 调试 |
| `-c` / `--rpm` / `--max-wait` | 自动 / 95 / 90 | 并发 / 单 key 每分钟上限 / 单请求最长等待 |
| 码 | — | `0` 全成 ｜ `1` 有请求失败 ｜ `2` 参数错 ｜ `3` 全 key 限流超时 |
## 失败处置
| 现象 | 原因 | 动作 |
|---|---|---|
| 全 401/403 | key 失效 | 换 key；该 key 自动冷却 1h |
| 大量 429 | 单 key 超 100 RPM | 降 `--rpm`，`--stats` 看冷却 |
| 持续 rps < 3 | 并发不足 | `-c 14` |
| `remaining` 偏小 | 本地记账未刷 | `--refresh-quota`（每 key ≥62s 一次） |
| 标题被截断 | `-s` 按 400 字符截断 | 改用 `-j` |
## 陷阱
- `/usage` 限 10 次/10 分钟：脚本已缓存 600s，禁手写循环查额度。
- 429 冷却期间请求转其它 key，不整体 sleep；别为此加全局重试。
