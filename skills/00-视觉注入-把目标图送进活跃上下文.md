# 视觉注入 — 图 → 活跃上下文
STATE ✓ 2026-10-24｜SCOPE 把图送进活跃宿主上下文（上游取图 + 准入 + 落地）｜SCRIPT `ctxinject.py`｜REF `memory/ctxinject-渲染与准入实测.md`
## 何时用
要把截图/图片/视频帧/网络图送进当前上下文（模型看见才能答）/已有图片文件要注入/图里小字看不清（先裁 ROI）/宿主里出现 `[图]` 占位没内容
## 命令
```bash
S=~/.config/cli-agent/skill/ctxinject.py
python3 $S hosts                                        # 取 PID
python3 $S shot  -o /abs/x.png                          # 截当前屏到文件
python3 $S auto  --pid PID                              # 截屏并注入（一步）
python3 $S inject --pid PID -w "标注" /abs/a.png /abs/b.png   # 注入已有图，批量=1 条消息
ffmpeg -ss 3 -i v.mp4 -frames:v 1 /abs/f.jpg            # 视频某刻取帧
```
## 参数 / 退出码
| 项 | 说明 |
|---|---|
| `--pid` | 必填；误注入不可撤回 |
| `-w` | 文字标注，恒在 content 最前 |
| 位置参数 | 只有位置参数算图，选项值不算 |
| 后缀白名单 | `.png .jpg .jpeg .gif .webp`，否则该参数当文本、静默无图 |
| 路径 | 目标进程可读的绝对路径、无空格；proot 的 `/root/...` 宿主看不见 |
| 码 | `0` 成功 ｜ `1` 有文件不存在（整批不注）｜ `2` 缺 `--pid` ｜ `3` 宿主忙已 defer |
## 失败处置
| 现象 | 原因 | 动作 |
|---|---|---|
| `err:no_such_image` | 路径错/含空格/proot | `readlink -f` 后重发 |
| `exit 0` 但无 `image_url` | 后缀不在白名单 | 转 png 后重注 |
| `exit 3` | 宿主在跑 RUN | 等 0.1–15s 补插，勿重跑 |
| 下一轮只见 `[图]` | 已过压缩边界 | 重注，并当轮出结论 |
| 全黑帧 | 息屏 | 点亮重截 |
## 陷阱
- 一次注入至多 1 条 user 消息；批量不逐张（逐张=N 次唤醒 + 边界移动）。
- 宿主把图压到长边 512、细节低档：清晰度只靠**裁 ROI**（长边 512 上下）提升，放大无效；数字见 REF。
- 注入即改历史：`--pid` 必填，事后不可撤回。
- 坐标未知时先注整屏定位，再注 ROI，共 2 条消息。
