# 运行时上下文注入
STATE ✓ 2026-10-24｜SCOPE 向活跃宿主 `mem_hist` 追加 1 条 `role=user`；只追加，无删改｜SCRIPT `ctxinject.py`｜REF `memory/archive/运行时注入-sys.remote_exec实测.md`
## 何时用
- 结论依赖画面，命令查不到（必须"看图"才能答）
- 要把一段文本塞进活跃上下文而不重启会话
- 上次注入返回 `3` 在排队，需要等它落地
- 只想存图 / 只查 PID → 不用本技能（存盘、`hosts` 即可）
## 命令
```bash
S=~/.config/cli-agent/skill/ctxinject.py
python3 $S hosts                                    # 候选宿主 pid+cmdline
python3 $S auto   --pid PID                         # 截屏+注入+唤醒
python3 $S inject --pid PID -w "text" a.png b.png   # N 图 1 条消息；也可只给文本
python3 $S shot   -o /abs/x.png [--device D] [--long N]
python3 $S gc                                       # 清 >3 天 payloads
L=~/.cache/ctxinject/watch_<PID>.log; for i in $(seq 120); do grep -qE '"ev":"(watch_ok|watch_timeout|watch_err)"' "$L" 2>/dev/null && break; sleep 5; done; tail -1 "$L"
```
## 参数 / 退出码
| 参数 | 说明 |
|---|---|
| `--pid` | 必填，缺 → `2` |
| `-w/--wake` | `SIGWINCH` 唤醒；目标未捕获 → `note.no_sigwinch` 且转排队 |
| `--timeout` | 默认 `8.0`；无 `-w` 时实际取 `min(timeout,2)` |
| `--device` | 默认 `127.0.0.1:7957`，不在在线列表则取首台 |
| `--text` | `auto` 的附图文本，默认「看图」 |
| 码 | `0` 已落地 ｜ `1` 参数/环境错 ｜ `2` 缺 `--pid` ｜ `3` 已排队 |
## 失败处置
| 现象 | 原因 | 动作 |
|---|---|---|
| `no_such_pid` / `target_is_self` | PID 错 | `hosts` 重取 |
| `cmd_fail` / `remote_exec 失败` | 解释器不匹配或目标已退 | 需同 UID + 同 CPython 小版本 |
| `defer.reason=busy` | 宿主在跑 RUN | 正常，走看守循环等 |
| `watch_timeout` | 600s 未落地 | 重注，勿并行多份看守 |
| `hist_len` +2 | 曾重跑 | 不可撤回；下次压缩一并处理 |
## 陷阱
- 注入 = 在运行进程里执行任意代码：必须**用户显式授权**后再跑。
- 前提：同 UID + 完全相同的 CPython 解释器；自测用假宿主，用完 `kill`。
- `SIGWINCH` 会打断宿主当前行输入，可能吞半行。
- 历史只追加：无 `drop`、无回滚；每条使 `hist_len`+1 并成为新 `last_u`，下次压缩吞掉它之前的全部。
- 图活到下次压缩，之后模型只看到 `[图]`。
- 禁 `pkill -f 'ctxinject.py watch'`（匹配自身 shell → 自杀），按 pid `kill`。
