# 00-长时任务监听
STATE ✓ 2026-11-26｜SCOPE 单次运行 ≥1 分钟的下载/编译/安装/构建，用一次调用取代轮询｜SCRIPT taskwatch.py
## 何时用
| 判据 | 说明 |
|---|---|
| 预计运行 >60s 或时长未知 | 下载、编译、`apt install`、打包 |
| 你正要第二次 `ps`/`ls` 查进度 | 停手，改用本技能 |
| 任务已在别处跑（tmux / 旧会话） | 用 `wait` 挂上去 |
## 命令
```bash
TW=~/.config/term_agent/skill/taskwatch.py
python3 $TW run -t dl --file ~/x.zip --min-size 1000000 -- wget -O ~/x.zip URL
python3 $TW run -t build --grep-done 'BUILD SUCCESSFUL' --grep-block '\[y/n\]' -- npm run build
python3 $TW wait -t dl --file ~/x.zip --min-size 1000000
python3 $TW wait -t ext --pid 12345 --file out.bin
python3 $TW peek -t dl; python3 $TW tail -t dl -n 50; python3 $TW ls; python3 $TW kill -t dl
```
## 参数 / 退出码
| 参数 | 默认 | 说明 |
|---|---|---|
| `-t/--tag` | run 取命令哈希 | 状态键，限 `A-Za-z0-9._-` 长度 ≤40 |
| `--timeout` | 1800 | 封顶 3300（宿主 3600 硬超时），到点不杀任务 |
| `--interval` | 5 | 轮询间隔秒 |
| `--file` `--min-size` | 无 / 0 | 产物判据：rc=0 且达标才 DONE |
| `--size-stable` | 15 | 无 pid 时大小稳定窗口秒 |
| `--grep-done` `--grep-block` | 无 | 日志正则，只读尾部 8KB |

| 输出行 | 含义 |
|---|---|
| `DONE 412s rc=0 size=104857600 frozen=0s` | 退出码 0 |
| `BLOCKED 3s why=timeout resume=1` | 退出码 1，任务仍在跑 |
| `frozen=Ns` | 被系统冻结秒数，不计入超时 |

退出码：`0`=DONE｜`1`=BLOCKED（**不是命令失败**）｜`2`=用法错
## 失败处置
| why | 研判 | 处置 |
|---|---|---|
| `rc` | 命令本身失败 | `tail -t <tag>` 看尾部 |
| `short` | rc=0 但产物不足 | 查 URL/磁盘，`ls -l` 产物 |
| `orphan` | 进程消失且 rc 未落盘 | 被 OOM/系统杀，抓 log 尾部 |
| `prompt` | 命中 `--grep-block` | `tail` 看提示，改命令加非交互参数 |
| `timeout` | 到监听上限 | `resume=1` → 同 tag 再发一次 `wait` |
| `interrupted` | 宿主被 Ctrl+C | 任务仍活，`peek` 后 `wait` 续听 |
## 陷阱
| 现象 | 原因 | 处置 |
|---|---|---|
| 立刻 `DONE rc=0` 但任务还在跑 | cmd 里用 `&` 后台化了 | 加 `--file` 或 `--grep-done` |
| 同 tag 再调不重启 | pid 活 + cmd 相同即续听（幂等） | 要重跑先 `kill -t` |
| 熄屏后长时间不动 | Doze 冻结 | `run` 默认取 wakelock，`--no-wake` 关闭；`frozen=` 有值即被冻 |
| 宿主报 `命令超时（3600秒）` | 宿主硬上限 | 任务因 setsid 未死，`wait -t <tag>` 续听 |
