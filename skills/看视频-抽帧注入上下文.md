# videowatch — 视频 → 有序时间戳帧 → 进上下文

## 何时用
- 用户发视频（链接或本地文件）问"讲了什么 / 画面是什么 / 里面写了什么字母"
- 别猜、别让用户口述，抽帧自己看

## 一条命令
```bash
python3 ~/.config/term_agent/skill/videowatch.py "<URL 或本地路径>"
```
退出码：`0` 已落地 / `3` 已排队（下一轮补插） / `1` 错 / `4` 回执图数不符 / `5` 关键帧全空场（未注入）

## 参数
| 参数 | 默认 | 说明 |
|---|---|---|
| `--thr` | 6.0 | 与上一保留帧的灰度均差阈值，调大只要大变化 |
| `--max-frames` | 16 | 硬上限，超限按分数 top-N 保序 |
| `--long` | 480 | 抽帧长边（受宿主 512 封顶） |
| `--budget` | 150000 | 注入 token 预算，超了自动降档/裁帧 |
| `--max-sec` | 900 | 时长闸门，超了直接报错 |
| `--no-inject` | | 只出图 |
| `--quiet` | | 排队注入不唤醒宿主 |

## 产物
```
~/.cache/videowatch/<hash10>/
  src.mp4 | f1/f%05d.jpg（自适应 fps 全量） | out/t<毫秒>_i<序>.jpg | manifest.json
```
`manifest.json` 每帧带 `t`(毫秒)/`sec`/`i`，二次分析直接读它。

## 用时必知
1. **RUN 内注入必然排队**（宿主 tool_calls 未收尾），图**下一轮**才看得见 —— 别重复跑，会插多条消息。
2. 路径不能含空格；产物一律落 `~/.cache`（/tmp 不可写）。
3. 基础帧率按时长自适应：`<30s→5fps`、`<120s→2fps`、其余 `1fps`；报秒数用 `sec`，别看文件名。
4. 抽出来全黑/全白会 `exit 5` 拒注入 → 调 `--thr` 或按秒手工抽帧（`ffmpeg -ss 3 -i x.mp4 -frames:v 1 hi.jpg`）。
5. `--long` 调大换清晰度**无效**（宿主 512 封顶）；小字请裁 ROI 单独发。

## 调参
| 症状 | 动作 |
|---|---|
| 帧太多/太贵 | `--thr 8~12` 或 `--max-frames 8` |
| 长视频 | `--max-sec 1800 --max-frames 12` |
| 只想拿图不进上下文 | `--no-inject` |
