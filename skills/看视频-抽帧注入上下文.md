# videowatch — 视频 → 有序时间戳帧 → 进上下文

## 何时用
- 用户发视频链接/文件并问"讲了什么 / 画面是什么 / 这段怎么样"
- 需要读视频里的画面、字幕、代码、操作步骤
- **不要靠猜或让用户口述**；抽帧自己看

## 一条命令
```bash
python3 ~/.config/term_agent/skill/videowatch.py "<URL 或本地路径>"
```
退出码：`0` 已落地 / `3` 已排队（看守自动补插） / `1` 错 / `4` 回执图数不符

## 机制（4 步，顺序固定）
1. **取源**：URL → `yt-dlp -f bv*[height<=720]`，落 `~/.cache/videowatch/<sha1(src)前10>/src.mp4`；同 URL 重跑复用不重下
2. **降采样**：`ffmpeg -vf fps=1,scale=W:H` 全片 1fps → `f1/f00001.jpg`
3. **变帧检测**：逐帧缩 `64×36` 灰度，与**上一保留帧**（不是上一帧）求 `ImageStat(difference).mean`；首帧必留，`≥thr` 留；超 `max-frames` 按分数 top-N 保序
4. **组织+注入**：`out/t<秒>_i<序>.jpg`（字典序=时间序）→ `ctxinject.py inject -w` 一条消息塞 N 图 → 宿主 `_img`（800 长边 + 216 色）→ `image_url` 进 `mem_hist`

## 参数
| 参数 | 默认 | 说明 |
|---|---|---|
| `--thr` | 6.0 | 相邻保留帧灰度均差阈值（0-255）。调大=只要大变化 |
| `--max-frames` | 16 | 硬上限，超限按分数 top-N 保序 |
| `--budget` | 150000 | 注入 token 预算。超了自动降长边 480→360→300→240→180，仍超则时间轴均匀裁帧 |
| `--long` | 480 | 抽帧长边；源更小则不放大 |
| `--max-sec` | 900 | 时长闸门，超了报错不硬跑 |
| `--no-inject` | | 只出图 |
| `--quiet` | | 不唤醒宿主，排队注入 |

## 成本（宿主 216 色 PNG，实测）
| 画面类型 | 长边 | 单帧 token |
|---|---|---|
| 纯色/UI 型 | 480 | 0.3k |
| 真实画面 320×176 | 原生 | 10k |
| 真实画面 1080p | 480 | **18.7k** |
| 1080p | 360 / 300 / 240 / 180 | 11k / 8k / 6.3k / 4k |
连续色调（影视/游戏）最贵，纯 UI 便宜 30 倍。16 帧 @480 ≈ 300k token → 默认 budget 150k 会自动降到 300 档。

## 必知失败模式
1. **RUN 内注入必然 `deferred: tool_calls 未收尾`** —— 宿主末条是带 `tool_calls` 的 assistant。看守每 2s 重试，tool 结果补齐后 **3~4s 自动补插**。
   → **抽帧那一轮看不见图，下一轮才看见，这是正常行为，不要重复跑**（会插多条 user 消息）。
2. 帧路径**不能含空格**（ctxinject 空格分隔多图）；本脚本命名 `t%06d_i%02d.jpg` 天生安全。
3. `/tmp` 不可写（Termux/proot）→ 产物一律 `~/.cache/videowatch/`。
4. 第 n 帧（1 基）≈ **n-1 秒**；`fps` 取 t≥k 的首帧，1fps 下误差 ≤1s。
5. 纯音频/损坏文件：probe 取不到 `v:0` 直接报错，不会硬抽黑帧。
6. **禁止在放大图上估成本**：拿 320×176 源 `scale` 到 480 测出的数字虚高 2 倍。估成本源分辨率必须 ≥ 目标档。

## 实测基线（2026-10-22｜ffmpeg 9.0.2 / Pillow 13）
| 样本 | 结果 |
|---|---|
| 三色段 8s 640×360 | 8→3 帧，**精确命中 0s/3s/6s** |
| 纯灰静止 10s | 10→**1 帧**（不误报） |
| testsrc2 运动 6s | 6→4 帧 |
| 1080p 60s | 42 命中→16 帧，全链路 **3 秒** |
| `--max-frames 2` | 6→2 帧，0s/4s **保序** |
| 注入 3 帧 300 长边 | image_url×3，27.2k token，牌子文字仍可读 |

## 调参口诀
| 症状 | 动作 |
|---|---|
| 帧太多 / 太贵 | `--thr 8~12` 或 `--max-frames 8` |
| 小字看不清 | `--long 640 --budget 300000` |
| 长视频 | `--max-sec 1800 --max-frames 12` |
| 只想拿图不进上下文 | `--no-inject` |

## 产物
```
~/.cache/videowatch/<hash10>/
  src.mp4 | f1/f%05d.jpg（1fps 全量） | out/t<秒>_i<序>.jpg | manifest.json
```
`manifest.json` = 源尺寸/时长/阈值/帧表，二次分析直接读它，不必重跑 ffmpeg。
